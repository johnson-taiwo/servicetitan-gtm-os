# ServiceTitan GTM Context OS

A Claude Code Context OS for **ServiceTitan**, the software platform for trade contractors (HVAC, plumbing,
electrical, roofing). Built by Johnson Taiwo for the Treford GTM Engineering Bootcamp, Cohort 1 (Nov 2026), from public
information plus first-hand list-building experience in the trades (marked "Source: practitioner"). Not affiliated
with ServiceTitan.

**The thesis.** Selling to trade contractors is a data problem before it is a copy problem. Most contractors are
invisible to B2B databases, and the ones that look small often aren't (field crews don't use LinkedIn). So this system
spends its effort on two things: a dated, physical reason to reach out (an office job post, technicians being hired, a
storm, a permit) and proving the company is big enough from public files before paying for a contact.
