# ServiceTitan GTM Context OS

A Claude Code Context OS for **ServiceTitan**, the software platform for trade contractors. It holds the company's
go-to-market context as plain text files: research with sources, ICP, personas, signal matrix, GTM system
architecture and a Clay-ready workflow spec. Built by Johnson Taiwo for the Treford GTM Engineering Bootcamp, Cohort 1
(Nov 2026), from public information plus first-hand list-building experience in the trades (marked as such).
Not affiliated with ServiceTitan.
